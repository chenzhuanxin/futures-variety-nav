# 期货品种资讯导航

国内商品与金融期货品种的资讯跳转工具。选定一个品种，一键直达它的**行情、持仓龙虎榜、股吧讨论、专家问答与视频搜索**入口。

在线使用：<https://chenzhuanxin.github.io/futures-variety-nav/>

> 说明：仓库名使用 ASCII 短横线格式（`futures-variety-nav`），因为 GitHub 的仓库名不接受中文字符——中文名会被自动清洗掉。

## 功能

- **品种矩阵**：按交易所分区的密集卡片网格，交易所品牌色编码，标注「夜盘 / 2023 年后上市」。
- **详情面板**：桌面端固定在右栏，移动端为底部抽屉；点选品种后不再离开当前位置。
- **深链**：地址栏 `#碳酸锂代码`（如 `#LC`）可直接打开某个品种，可分享、可收藏，浏览器前进后退可用。
- **检索与筛选**：支持名称 / 代码 / 拼音 / 板块 / 交易所检索，可按交易所、板块、夜盘、新上市、收藏筛选。
- **收藏**：收藏结果存在浏览器本地（`localStorage`），不涉及任何服务端。
- **配色**：跟随系统 / 浅色 / 深色三种模式。
- **键盘**：`/` 聚焦搜索框，`Esc` 关闭面板或清空搜索，方向键在矩阵中移动，`Tab` 顺序遍历。
- **批量操作**：一键打开某品种的全部入口，或复制全部链接。
